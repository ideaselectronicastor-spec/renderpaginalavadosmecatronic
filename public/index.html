Guía de la API

Base URL: {{BASE}}

GET /health

Verifica que el servicio esté activo.

curl {{BASE}}/health

POST /v1/check

Consulta una tarjeta RFID. Requiere header X-Device-Key.

curl -X POST {{BASE}}/v1/check \ -H "Content-Type: application/json" \ -H "X-Device-Key: dev_tu_api_key" \ -d '{"uid": "A1B2C3D4"}'

POST /v1/charge

Cobra saldo al usuario. Requiere header X-Device-Key.

curl -X POST {{BASE}}/v1/charge \ -H "Content-Type: application/json" \ -H "X-Device-Key: dev_tu_api_key" \ -d '{"uid": "A1B2C3D4", "amount": 5}'

GET /api/users

Lista todos los usuarios.

POST /api/users

Crea un usuario nuevo.

curl -X POST {{BASE}}/api/users \ -H "Content-Type: application/json" \ -d '{"rfidUid": "A1B2C3D4", "name": "Juan", "balance": 20}'

POST /api/users/:id/recharge

Recarga saldo a un usuario.

curl -X POST {{BASE}}/api/users/1/recharge \ -H "Content-Type: application/json" \ -d '{"amount": 10}'

GET /api/transactions

Historial de movimientos (últimos 200).

GET /api/devices

Lista dispositivos ESP32 y sus API keys.

POST /api/devices

Registra un nuevo dispositivo ESP32.

GET /api/settings

Obtiene configuración (cobro, moneda, saldo mínimo).

PATCH /api/settings

Actualiza configuración.

Código ESP32

const char* API_BASE = "{{BASE}}"; const char* DEVICE_KEY = "dev_tu_api_key";
