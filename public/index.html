Guía para principiantes — ESP32 + API

¿Qué es esto?

Tu ESP32 se conecta por WiFi a esta URL y habla con el servidor para saber si una tarjeta RFID tiene saldo y cobrar el lavado. No necesitas saber programar servidores: solo copia los ejemplos en tu código Arduino.

Tu URL base: {{BASE}}

⚠ Render se duerme: En plan gratis, si nadie usa la API ~15 minutos, el servidor entra en reposo. La primera petición puede tardar 30–60 segundos. Solución: llama primero a GET /v1/status para despertarlo, espera la respuesta, y luego haz check/charge.

0 Despertar el servidor (importante)

Antes de cualquier operación, pregunta si el servidor está listo. No necesitas API Key ni tarjeta. Solo quieres que responda status: ok.

Petición

GET/v1/status

Respuesta esperada
{ "success": true, "status": "ok" }
Probar en navegador
{{BASE}}/v1/status
Pulsa "Probar despertador" arriba

1 Obtén tu API Key

Cada ESP32 necesita una clave única para identificarse:

  • Ve a la pestaña Dispositivos en este panel
  • Copia la API Key (empieza con dev_)
  • Pégala en tu código como DEVICE_KEY

2 Consultar tarjeta (antes de lavar)

El ESP32 lee la tarjeta y pregunta: ¿este cliente existe? ¿tiene saldo?

POST/v1/check

Header obligatorio: X-Device-Key: dev_tu_api_key

Cuerpo JSON (body)
{ "uid": "A1B2C3D4" }
Si todo bien, recibes
{ "success": true, "found": true, "name": "Carlos", "balance": 20, "canUse": true }

Si canUse es false, no tiene saldo suficiente → no abras el lavado.

3 Cobrar el lavado

Si el cliente puede usar el servicio, cobras el monto configurado en Configuración.

POST/v1/charge

Header obligatorio: X-Device-Key: dev_tu_api_key

Cuerpo JSON (body)
{ "uid": "A1B2C3D4", "amount": 5, "description": "Lavado automatico" }
Respuesta exitosa
{ "success": true, "charged": 5, "balance": 15 }

4 Orden recomendado en tu ESP32

  1. Conectar WiFi
  2. GET /v1/status → esperar respuesta (despertar Render)
  3. Leer tarjeta RFID → obtener UID en mayúsculas (ej. A1B2C3D4)
  4. POST /v1/check → verificar saldo
  5. Si canUse == true → POST /v1/charge
  6. Activar relé / bomba de agua

5 Código ejemplo ESP32 (Arduino)

const char* API_BASE = "{{BASE}}"; const char* DEVICE_KEY = "dev_tu_api_key"; // Despertar Render antes de usar la API bool wakeServer() { HTTPClient http; http.begin(String(API_BASE) + "/v1/status"); http.setTimeout(60000); // 60 seg — Render puede tardar al despertar int code = http.GET(); http.end(); return code == 200; } // Llamar al inicio del loop o antes de processCard(): wakeServer(); delay(500);

Errores comunes

  • Timeout / no responde → El servidor duerme. Llama /v1/status primero y usa setTimeout(60000).
  • invalid_device_key → API Key incorrecta. Revisa en Dispositivos.
  • insufficient_balance → Cliente sin saldo. Recarga desde el panel.
  • uid_required → Envía el UID de la tarjeta en el JSON.
